# 🚀 AI Full Stack Project

## 📌 Overview

This project is a full stack AI-powered application built using:

* FastAPI (Backend)
* PostgreSQL (Database)
* Google Sheets API (Data Sync)
* LLM (AI Responses)

## ⚙️ Features

* Store user data in PostgreSQL
* Sync data to Google Sheets
* AI-generated responses
* REST API with FastAPI

## 🛠️ Tech Stack

* Python
* FastAPI
* PostgreSQL
* SQLAlchemy
* Google Sheets API

## ▶️ Run Locally

```bash
uvicorn app.main:app --reload
```

## 📂 Project Structure

* app/main.py → API routes
* app/models.py → Database models
* app/database.py → DB connection
* app/ai.py → AI logic
* app/sheets.py → Google Sheets integration
